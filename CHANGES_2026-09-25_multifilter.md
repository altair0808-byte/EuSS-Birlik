# Мульти-выбор фильтра «Объект/Отдел» (в работе, часть 1)

## Готово

**Frontend** (`index.html`):
- `state.org.object` / `state.org.department` — теперь массивы, не строки (с авто-миграцией
  старого значения из sessionStorage, чтобы у тех, кто уже открыл вкладку, ничего не сломалось).
- Единый фильтр вверху страницы (виден на «Сотрудники», «Курсы», «Назначения», «Протоколы»,
  «Сертификаты», «Календарь», «Главная») — переделан из двух `<select>` в чекбокс-дропдауны:
  можно отметить сразу несколько объектов и/или отделов, кнопка «Очистить» на каждое поле,
  закрытие по клику вне дропдауна.
- Модалка «Экспорт в Excel» использует свои собственные независимые поля Объект/Отдел
  (как и раньше) — их не трогал; если в едином фильтре выбран ровно один объект/отдел,
  он подставляется как значение по умолчанию.

**Backend** — принимают `?object=A,B&department=X,Y` (через запятую) вместо одного значения,
через новый `lib/multiFilter.js` (`splitMulti`) и `= ANY($::text[])`:
- `routes/users.js` (было сделано раньше)
- `routes/courses.js` — список курсов + сводная статистика
- `routes/protocols.js` — список протоколов
- `routes/assignments.js` — список назначений, `/expiring` (истекающие), `/certificates`
- `routes/export.js` — экспорт в Excel

Обратная совместимость сохранена: одно значение или пустой параметр работают как раньше.
