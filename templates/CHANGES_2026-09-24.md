# Изменения по запросу от 24.09.2026

## 1. Назначение курса из карточки сотрудника
- На странице карточки сотрудника (панель профиля) появилась кнопка «+ Назначить курс».
- Открывает то же окно назначения теста, что и на вкладке «Назначения», но
  заблокированное на этом одном сотруднике (список выбора сотрудников скрыт,
  показано только его ФИО). После назначения карточка сотрудника обновляется
  автоматически.
- Файлы: `index.html` (функции `assignModalHtml`, `openAssignModal`,
  `submitAssignForm`, `loadUserProfile`).

## 2. Положение печати на сертификате
- Печать на сертификате смещена примерно на 3 см левее (ближе к подписи).
- Файл: `routes/certificate.js` — добавлена константа `STAMP_SHIFT_LEFT = 30 * MM`
  и применена при расчёте `stampCenterX`.
- Если после проверки на реальном примере понадобится другое смещение —
  значение легко поправить в одной строке (`30 * MM` = 3 см; уменьшить/увеличить
  можно, поменяв число 30).

## 3. Настройка «Следующий протокол» — пояснение
Функционал не дублирует, а дополняет открытие протокола:
- **«Открыть протокол»** (вкладка «Протоколы») — диапазон дат, в течение
  которого номер присваивается автоматически ВСЕМ, кто сдаст тест в эти дни,
  независимо от того, что было введено вручную при назначении.
- **«Следующий номер протокола»** (в настройках) — это просто подсказка/счётчик
  для поля номера протокола, когда админ вручную назначает тест или вносит уже
  пройденное ранее обучение (и протокол в данный момент не открыт). При сдаче
  теста этот номер будет автоматически заменён номером активного протокола,
  если такой найдётся на дату сдачи.
Рекомендация: если два эти механизма продолжают путать администраторов на
практике, можно добавить более явную подсказку в интерфейсе рядом с полем
настройки — дайте знать, и мы это добавим.

## 4. Учёт сотрудников, не прошедших обязательное обучение
- У курса появился флажок «Обязательный курс для всех сотрудников»
  (поле `is_mandatory` в таблице `courses`).
- На карточке курса — бейдж с количеством сотрудников, которые добавлены в
  систему, но ещё ни разу не сдали этот курс; по клику открывается список
  с возможностью перейти в карточку сотрудника или сразу назначить курс всем
  из списка одной кнопкой.
- Новые эндпоинты:
  - `GET /api/courses/:id/untrained` — список сотрудников без пройденного курса
  - `GET /api/courses/stats/summary` — сводная статистика по всем курсам
- Файлы: `db.js` (миграция), `routes/courses.js` (эндпоинты),
  `index.html` (чекбокс в форме курса, бейдж на карточке, модальное окно
  «Не прошли обучение»).

## 5. Статистика на главной странице по видам курсов
- На главной странице появился блок «Статистика по курсам» с вкладками
  (чипами) — по одной на каждый курс. При выборе курса показываются:
  сотрудников всего, прошли обучение, ожидают прохождения, не сдали,
  просрочено, и (если курс обязательный) — не прошли обучение.
- Отдельная плашка «Не прошли обязательное обучение (хотя бы по одному
  курсу)» в верхней части статистики — общее число сотрудников по всем
  обязательным курсам сразу.
- Файлы: `index.html` (`loadDashboardCourseStats`, `renderDashCourseTabs`,
  `renderDashCoursePanel`), `routes/courses.js` (`GET /stats/summary`).

## Что стоит проверить перед продакшеном
- Смещение печати на 3 см — визуально сверьте на реальном примере с бланком
  печати вашей организации; при необходимости легко скорректировать.
- Флажок «Обязательный курс» нужно проставить вручную на нужных курсах
  (например, на курсе по БиОТ/вводному инструктажу) — по умолчанию у всех
  курсов он выключен, чтобы не менять поведение существующих курсов.
- Миграция в `db.js` выполняется автоматически при следующем запуске сервера
  (`ALTER TABLE ... ADD COLUMN IF NOT EXISTS is_mandatory`).
