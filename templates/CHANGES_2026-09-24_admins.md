# Админы вне статистики + вкладка «Администраторы» (24.09.2026)

## Что не учитывает администраторов (только `role = 'employee'`)
- Главная: счётчики, статистика по курсам (сдали / ожидают / не сдали / просрочено), «Скоро истекает».
- Вкладки «Сотрудники», «Назначения / Журнал», «Календарь», «Протоколы» (число сотрудников и состав Word-протокола).
- Экспорт в Excel.
- Фильтр «Объект / Отдел» строится только по сотрудникам.
- Серверные изменения: `routes/users.js`, `routes/assignments.js`, `routes/courses.js` (`/stats/summary`),
  `routes/export.js`, `routes/protocols.js`.

## Вкладка «Администраторы» (только суперадмин)
- Отдельный список админов: добавить, изменить (логин/пароль/данные/роль), удалить. Без импорта Excel, фильтра
  объект/отдел и карточки обучения.
- `GET /api/users` теперь по умолчанию отдаёт только сотрудников; `?role=admin` — только для суперадмина
  (админу — 403). Фильтр по роли во вкладке «Сотрудники» убран.
- Смена роли в форме (суперадмин) переносит человека между вкладками.

## Назначение курсов
- `POST /api/assignments` и `/bulk` принимают только сотрудников (для админа — 400 «Курсы можно назначать только сотрудникам»).
- Старые записи обучения, если они были у админов, остаются в базе, но нигде не показываются и не считаются.
