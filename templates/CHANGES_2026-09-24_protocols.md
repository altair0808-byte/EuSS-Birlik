# Протоколы: годы, нумерация, Word (24.09.2026)

## Настройки
- Из «Настроек» убраны «Префикс номера протокола» и «Следующий номер протокола» (фронтенд и `PUT /api/settings`).
  Нумерация сертификатов осталась как была. Колонки `protocol_prefix` / `protocol_next_number` в БД не трогали.
- Счётчик протоколов больше не двигается при назначении/импорте (`advanceProtocolCounter` удалён).

## Вкладка «Протоколы»
- Подвкладки по годам (год = год даты открытия): 2025, 2026, 2027… Появляются сами, когда открывается протокол
  за новый год; текущий год показан всегда. На вкладке — счётчик протоколов.
- Внутри года сортировка по дате открытия (кнопка переключает «новые сверху / старые сверху»).
- «Открыть протокол»: номер подставляется автоматически — следующий после максимального за год даты открытия
  (`027` → `028`, формат сохраняется). Можно стереть и ввести вручную. При смене даты открытия на другой год
  предложение пересчитывается (если номер не правили руками). Пустой номер сервер тоже заполнит сам.
- Номер уникален в пределах года (дубль → сообщение «Протокол № … уже существует»).
- `GET /api/protocols/next-number?year=YYYY` — новый эндпоинт. В форме «Назначить тест» подсказка номера
  теперь: номер действующего сегодня протокола, иначе — следующий по нумерации текущего года.
- Даты протоколов отдаются строкой `YYYY-MM-DD` (раньше — Date, из‑за часового пояса могли «съехать» на день).

## Word-протокол (`GET /api/protocols/:id/download`, кнопка «Скачать Word»)
- Шаблон `templates/protocol_template.docx` — копия образца «Протокол по БиОТ № 027» (шапка, логотип, таблица, подписи).
- Имя файла: `2026-09-20 Протокол по БиОТ № 027.docx` (дата открытия + номер).
- В шапке: `2026 жылғы / года / year « 20 » Сентябрь / № 027` — из даты открытия и номера.
- Таблица (генератор — `protocolDocx.js`, зависимость `jszip`): № п/п · № сертификата сотрудника ·
  ФИО (кириллицей) · № пропуска ТШО · должность · отдел (если пуст — объект) · отметка · примечание.
  «Прошел» / «Подлежит повторной проверке знаний». Шапка таблицы повторяется на каждой странице.
- Кириллица: латинские «двойники» внутри русских слов (`Kуанышбекова`) заменяются на кириллицу; ФИО, целиком
  написанное латиницей, транслитерируется (эвристика — казахские имена лучше проверять глазами).
- Новое поле сотрудника «№ пропуска ТШО» (`users.tco_badge`; форма сотрудника, API, импорт Excel — колонка
  «№ пропуска ТШО»).
- В протокол попадают сотрудники, сдавшие/не сдавшие тест в период действия протокола, а также записи
  с тем же номером и датой протокола, внесённые вручную/импортом. Теперь протокол присваивается и тем, кто не сдал.
