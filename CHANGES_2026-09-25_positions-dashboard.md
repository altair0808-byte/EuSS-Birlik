# Должности (RU/KZ) и карточки дашборда (25.09.2026)

## 1. Справочник «Должность» — теперь двуязычный
Раньше `positions_list` в настройках был плоским списком строк (одна должность —
одна строка на одном языке). Теперь каждая запись — `{ru, kz}`.

- `routes/settings.js`: `GET/PUT /api/settings/dictionaries` принимают и отдают
  должности как `{ru, kz}` (старый формат «просто строка» по-прежнему принимается
  на вход и автоматически оборачивается — ничего не сломается, если где-то
  останутся старые данные).
- `db.js`: при следующем запуске сервера, если справочник должностей пуст,
  автоматически заполняется 58 позициями из присланного файла
  `Dome 6 MT position - 19.09.2025.xlsx` (русский + казахский). Существующие
  записи никогда не перезаписываются.
  ⚠️ У должности «Camp Manager» в файле не было русского перевода (пустая
  ячейка) — вписал сам: «Менеджер городка». Если у вас есть официальное
  название — поправьте в Настройках, это обычная запись справочника.
- `index.html`: у сотрудника в карточке по-прежнему хранится ОДНО (русское)
  значение `position` — это канонический текст для фильтров/экспорта. Казахское
  отображение подставляется на лету функцией `posLabel()` при переключении
  интерфейса на казахский (по совпадению с русским значением в справочнике) —
  без изменения структуры таблицы `users`.
- Список должностей в карточке сотрудника, поиск, таблица сотрудников, экспорт
  CSV из блока «Скоро истекает» — везде показывается перевод при казахском
  интерфейсе.
- Вкладка «Настройки → Отделы и должности»: для должности теперь два поля
  (русский + казахский) при добавлении, в списке значения показаны как
  «Русский — Қазақша».

## 2. Карточки на главной странице
Убрано: «Курсы и тесты», «Назначено тестирований (всего)», «Пройдено
(сдано/не сдано)» (было одно число на два статуса), «В норме (срок не истёк)».

Вместо этого — один ряд из 6 карточек:
Сотрудников всего · Прошли обучение · Ожидают прохождения · Не сдали ·
Просрочено · Не прошли обязательное обучение (эта последняя, как и раньше,
показывается только если в системе вообще есть обязательные курсы).
