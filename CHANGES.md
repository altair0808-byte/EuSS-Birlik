# Функции администраторов (БиОТ / внутреннее / внешнее обучение / мед. книжки)

Суперадмин выдаёт каждому администратору одну или несколько функций. Админ работает только с тем, что ему выдано;
всё остальное скрыто в интерфейсе и закрыто на сервере (проверка идёт на каждый запрос, по данным из БД).

- `БиОТ` — наши курсы с тестом (course_kind = internal), назначения, протоколы, удостоверения, сертификаты.
- `Внутреннее обучение` — курсы «без протокола» (no_protocol) и группы обучения по ним.
- `Внешнее обучение` — внешние курсы (external) и группы по ним.
- `Мед. книжки` — раздел мед. книжек (должности, периодичность, записи сотрудников).

**Миграция.** При первом запуске в БД появляется `users.admin_functions`, и всем уже существующим админам выдаются ВСЕ четыре
функции (ничего не пропадает). Новые админы создаются без функций, пока суперадмин их не отметит. Суперадмин и ассистент не затронуты.

**Сервер:** `lib/adminFunctions.js` (константы, проверки, middleware), `routes/auth.js` (`/api/auth/me`, функции в токене/логине),
`routes/users.js` (поле `admin_functions`, только суперадмин), `courses.js`, `assignments.js`, `protocols.js`, `trainingSessions.js`,
`bulkTraining.js`, `coursePositions.js`, `medbooks.js`, `export.js`.
**Интерфейс:** чекбоксы в карточке администратора, функции в списке «Администраторы и ассистенты», скрытие вкладок,
дашбордов и видов курса в форме курса.

# Исправление: «На экран Домой» открывает сайт, а не приложение

**Причина.** `manifest.webmanifest` ссылался на `/icons/icon-512.png`, `/icons/maskable-192.png`, `/icons/maskable-512.png`,
а на сервере их не было (в репозитории лежал только `icon-192.png`, и не в `assets/icons/`, а в `assets/fonts/icons/`).
Без иконки 512x512 Chrome не считает сайт устанавливаемым приложением и добавляет обычную закладку.

**Что сделано**
- `assets/icons/`: созданы `icon-192.png`, `icon-512.png`, `maskable-192.png`, `maskable-512.png`; добавлены `apple-touch-icon.png`, `favicon-*`.
- `public/manifest.webmanifest`: иконки приведены в соответствие с файлами.
- `Server.js`: `/icons` отдаётся и из `assets/fonts/icons/` (запасной путь), чтобы ошибка с папкой не повторилась.

**После выкладки на телефоне:** удалить старый ярлык с экрана «Домой», открыть сайт в Chrome (Android) / Safari (iPhone) и добавить заново.
