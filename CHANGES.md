  прямо в карточке сотрудника (кнопка «Изменить» → поле «№ сертификата»). Это отдельное поле

## 3. Материалы и видео курса — отдельно на русском и казахском
- В курсе теперь два слота материалов (PDF/PPT/PPTX) — отдельно RU и KZ — и два слота видео

- Сотрудник в разделе «Мои тесты» видит материалы/видео на языке интерфейса, который у него

- Старые курсы (созданные до обновления) продолжают показывать раньше загруженный файл как RU.

# Обновление: сертификат, хранилище файлов, комиссия из двух председателей

## 1. Визуал сертификата (routes/certificate.js)
Подпись и печать перекрывали друг друга и выглядели мелко и хаотично. Переработано:
- Подпись теперь крупная (150×55) и всегда лежит в своей выделенной зоне.
- Печать крупная (95×95) и накладывается ТОЛЬКО на саму картинку подписи председателя 1
  (стандартная практика заверения), но подобрана по высоте так, чтобы не задевать ни строку
  с ФИО под линией, ни вторую подпись — между двумя колонками подписей теперь всегда зазор 90pt.
- Логотип, печать и обе подписи подгружаются один раз в начале генерации PDF (а не по очереди
  прямо во время рисования), поэтому больше нет риска "проглоченной" ошибки при недоступной
  ссылке на файл.

## 2. Файлы (логотип/печать/подписи/материалы/тесты) — в Supabase Storage
Раньше материалы и видео курсов лежали на локальном диске сервера (терялись при редеплое на
большинстве хостингов), а логотип/печать/подпись — как base64 прямо в таблице `settings`
(раздувало базу, приходилось гонять их туда-обратно). Теперь всё грузится один раз в Supabase
Storage, а в базе хранится только ссылка:
- Новый файл `supabaseStorage.js` — обёртка над `@supabase/supabase-js` (bucket создаётся
  автоматически при первой загрузке).
- `upload.js`: добавлен `makeMemoryUploader()` — файл читается в память и сразу уходит в
  Storage, локальный диск сервера больше не используется для этих файлов.
- `routes/settings.js` (логотип, печать, подписи), `routes/courses.js` (материалы курса,
  видео, Excel с тестами) — переведены на загрузку через Supabase Storage.
- **Нужно задать переменные окружения** `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` (Supabase
  Dashboard → Project Settings → API — это НЕ то же самое, что `DATABASE_URL`). Без них загрузка
  файлов вернёт понятную ошибку с указанием, что настроить. См. `.env` для примера.

## 3. Комиссия: только два председателя, без "членов комиссии"
- `routes/settings.js`: убраны `member2_name`/`member3_name`/`active_chairman` — теперь ровно
  два председателя (`chairman1_name/position`, `chairman2_name/position`), у каждого своя
  подпись (`POST /api/settings/signature?chairman=1|2`).
- `routes/certificate.js`: на сертификате всегда обе подписи (если заполнен только один
  председатель — рисуется одна широкая колонка, без пустого места).
- Вкладка "Настройки": два блока "Председатель комиссии 1/2" (ФИО + должность) вместо
  председатель+2 члена комиссии; отдельная загрузка подписи для каждого из двух.
- Старые колонки `member2_name`, `member3_name`, `active_chairman`, `chairman_name`,
  `signature_path` в базе не удалялись (чтобы не потерять данные без явной просьбы), но больше
  нигде не используются.

## 4. Протоколы (открытие/закрытие по датам)
Уже было полностью реализовано в прошлой итерации (таблица `protocols`, вкладка "Протоколы",
автоприсвоение номера протокола при сдаче теста в открытый период) — дополнительных изменений
не потребовалось.

# Обновление: размеры печати/подписи на сертификате, категории курсов

## 1. Сертификат: печать и подпись в реальных размерах (routes/certificate.js)
- Размеры теперь заданы в миллиметрах: круглая печать — 42 мм, подпись — до 55 × 22 мм
  (страница PDF = A4 альбомная 297 × 210 мм, поэтому при печати в масштабе 100% на бумаге
  получаются именно эти размеры).
- Загруженные изображения печати и подписи автоматически «подчищаются»: белый фон скана/фото
  становится прозрачным, пустые поля по краям обрезаются. Раньше из-за полей вокруг оттиска
  он выглядел в 1,5–2 раза мельче размера файла. Печать больше не закрывает подпись белым фоном.
- Блок подписи перекомпонован: печать накладывается на правую часть подписи и смещается в сторону
  ровно настолько, чтобы не заходить на должность и ФИО (считается по реальной ширине текста).
- Название курса на сертификате ограничено двумя строками, чтобы не наезжать на дату выдачи.
- Новая зависимость: `sharp` (нужен `npm install`). Если пакет не установлен — сертификат
  формируется как раньше, без автообрезки полей.

## 2. Систематизация обучения: категории курсов
- У курса появились поля «Категория (RU/KZ)» (карточка курса → «Изменить»). Колонки
  `courses.category_ru/category_kz` добавляются автоматически при старте сервера.
- Вкладка «Курсы и тесты»: курсы собраны в разделы по категориям (сворачиваются), сверху —
  поиск и быстрые фильтры-чипы. У каждой категории свой постоянный цвет — он же используется
  на других страницах. Новый курс, созданный при открытом разделе, сразу получает его категорию.
- «Назначить тест»: список курсов сгруппирован по категориям.
- «Назначения / Журнал»: у курса виден бейдж категории, добавлен фильтр по категории.
- «Мои тесты» (сотрудник): сверху сводка (к прохождению / сдано / не сдано), курсы разложены по
  разделам; разделы, где есть что проходить, идут первыми, внутри раздела — сначала несданное.
- Если ни у одного курса нет категории, все страницы выглядят почти как раньше (плоский список).

# Обновление: главная (скоро истекает срок) и бессрочные курсы

## 1. Главная: блок «Скоро истекает срок сертификата»
- Рядом с ФИО теперь название курса в рамке. Цвет рамки и фона — цвет категории курса
  (тот же, что на вкладке «Курсы и тесты», в «Мои тесты» и в журнале). Курсы без категории — серая рамка.
- Объект / отдел вынесены на вторую строку.

## 2. Бессрочные курсы
- В карточке курса появился флажок «Бессрочный курс» (поле «Срок (мес)» при этом отключается).
  Колонка `courses.no_expiry` добавляется автоматически при старте сервера.
- После сдачи теста по бессрочному курсу дата «следующее прохождение» не ставится (NULL) —
  сотрудник не попадает в «Скоро истекает срок» и не считается просроченным. То же для
  исторических записей (ручное внесение и импорт из Excel): дата для бессрочных курсов игнорируется.
- На сертификате вместо даты «Действителен до» печатается «бессрочно / мерзімсіз».
- Главная: сданные бессрочные курсы считаются «В норме». В карточке сотрудника в колонке
  «Следующее прохождение» — «Бессрочно». В списке курсов вместо срока — «∞ бессрочно».
- Переключение флажка у курса, по которому уже есть сданные тесты: при включении у них убирается
  дата следующего прохождения; при выключении — считается заново (дата сдачи + срок курса в месяцах).
  Вручную выставленные ранее даты при этом не сохраняются.
