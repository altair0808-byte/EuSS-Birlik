## 3. Номер сертификата = логин (и для уже существующих сертификатов)
Раньше «логин → номер сертификата» работало только для НОВЫХ сертификатов (когда сотрудник
только что сдал тест). Теперь при сохранении карточки сотрудника (создание логина, смена логина,
очистка ручного «№ сертификата»), если у него уже есть выданные сертификаты (assignments с
заполненным certificate_number), они сразу пересчитываются на актуальное значение:
  - если задан ручной «№ сертификата» в карточке — используется он (как и раньше, приоритет);
  - иначе — логин;
  - если и то, и другое пусто — старые номера НЕ трогаются (чтобы не обнулить уже
    распечатанные сертификаты просто потому, что у сотрудника временно нет логина).

Пример: было — сотрудник получил сертификат до того, как ему завели логин 1200 (номер
присвоился по старой сквозной нумерации). Теперь при сохранении карточки с логином «1200»
номер на всех его сертификатах станет «1200» автоматически.
